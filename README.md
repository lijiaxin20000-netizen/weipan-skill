# 尾盘Skill：30分钟决策器

一句话：**输入一份自选股，输出一张尾盘结果表。**

尾盘Skill是一个面向A股短线用户的尾盘观察工具。它不预测明天涨跌，也不提供买卖建议。它只在每天14:30之后，帮助用户判断：

> 今天尾盘，哪些股票更值得观察，哪些应该排除。

## 用户怎么用

1. 每天14:30后打开工具
2. 输入自己关注的股票名单，一行一个
3. 选择模式：稳健模式 / 进攻模式 / 避坑模式
4. 点击生成，得到一张尾盘结果表
5. 第二天开盘后，复盘昨天的尾盘结果是否有效

## 输出结果

工具只输出三个标签：

| 结果 | 含义 |
|---|---|
| 重点观察 | 尾盘结构较强，明天重点看承接 |
| 只看不追 | 有异动，但信号不完整 |
| 今日排除 | 尾盘诱多、高位回落、量能不足等风险较高 |

## 当前版本说明

当前是前端MVP演示版：

- 用户输入股票名单
- 页面生成模拟尾盘结果
- 用于展示产品交互和交付形态

真正上线时，需要接入行情数据接口，由后台自动补齐：

- 当前涨跌幅
- 成交额
- 量比
- 均线位置
- 14:30后涨跌幅
- 尾盘成交变化
- 板块强弱
- 主力资金

## 本地运行

```bash
npm install
npm run dev
```

## 打包

```bash
npm run build
```

## 部署到 GitHub Pages

本项目已经包含 `.github/workflows/deploy.yml`。

1. 把项目上传到 GitHub
2. 进入仓库 Settings → Pages
3. Source 选择 GitHub Actions
4. push 到 main 分支后自动部署

如果你的仓库名不是 `weipan-skill`，请修改 `vite.config.js` 里的：

```js
base: '/你的仓库名/'
```

## 风险提示

本工具仅用于行情结构分析和投资研究辅助，不构成任何投资建议。股票市场有风险，历史信号不代表未来收益。
